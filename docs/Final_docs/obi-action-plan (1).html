How to read this plan

Seven phases in order. A phase has major steps. A major step has substeps. Each substep is one thing that must be true, with the test that proves it and the instruction to give Claude Code. Tick a substep only when its test is green. A phase ends with a gate: every line in it must be true before the next phase starts.
