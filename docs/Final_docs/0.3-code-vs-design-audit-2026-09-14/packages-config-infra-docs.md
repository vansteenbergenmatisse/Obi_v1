# packages-config-infra-docs

## Purpose (two lines)
`packages/` holds the two cross-boundary contracts shared by `apps/web` and `apps/automation` (wire-shape types, design tokens). `config/` holds the two JSON registries that are the whole of "config is data" (tags, platforms) plus one prompt-text markdown; `infra/` holds the local Postgres compose stack; `docs/` holds the ADRs, plan ledger, runbooks and design-page source that govern everything else.

## External calls
None. Nothing in `packages/`, `config/`, `infra/`, or `docs/` makes an outbound network call itself. `infra/foundation/docker-compose.yml:7` pulls a pinned image digest (`pgvector/pgvector:pg16@sha256:1d5335...`) at `docker compose up` time — a one-time image pull, not a runtime client call, so no timeout/retry/breaker applies here.
