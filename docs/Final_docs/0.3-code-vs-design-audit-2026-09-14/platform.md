# platform

## Purpose (two lines)
`apps/automation/app/platform/` is the app-wide technical plumbing shared by every feature: the ORM tables/enums/roles/RLS policies for the one Postgres+pgvector store (`db/`), the outbound gateways to Confluence, the embedding providers, the reranker and Claude (`clients/`), environment settings plus the tag/platform registries (`config/`), the crash-safe job queue (`jobs/`), and structured logging (`logging/`). It imports no feature (boundary rule 4).
