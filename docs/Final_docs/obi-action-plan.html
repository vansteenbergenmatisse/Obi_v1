How to read this plan

Seven phases in order. A phase has major steps. A major step has substeps. Each substep is one thing that must be true, with the test that proves it and the instruction to give Claude Code. Tick a substep only when its test is green. The first line of every step and substep says what it does and why, in one or two sentences. Under the instruction sits a Check it list: Open or Run says what to do, See says what you must see, Break it says how to prove the test is real. A step that only makes a document gets one look at that document. A phase ends with a gate: every line in it must be true before the next phase starts.

   - Run them. New behavior: they fail for the stated reason. Regression: they pass.
3. Implement

7. Stop
   - Ask for /compact-ultra. Do not start the next substep.
