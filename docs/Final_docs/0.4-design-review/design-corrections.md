# 0.4.2 — Design corrections

One row per panel whose `today` line and/or status word was rewritten to match the
0.4.1 synopsis audit's proof. Targets, titles and code locations were left untouched
(see the hand-back for the panels whose "wrong" text lived in those fields instead —
those are out of scope for this substep and are listed as not-applied, with why).

52 panels were corrected — more than the 45-bullet "design is wrong here" list in
`delta.md`, because several bullets there group multiple panel ids under one wrong/right
pair (e.g. the six-panel per-user-identity bullet, the four-panel `scope_state`
bullet). Each affected panel gets its own row here since each panel carries its own
`today` field. One deviation beyond that: `cm-alembic`'s stale "Live head on Supabase:
0009" was also corrected, using the exact evidence already gathered for `ov-corpus`
(same fact, same citation), even though `cm-alembic` was not separately enumerated in
the 45-bullet list. See the hand-back for the full explanation.
